# MOEX Data Loader (Airflow + ClickHouse)

Небольшой ETL-пайплайн для сбора котировок (свечей) акций с Мосбиржи и сохранения их в ClickHouse. 
Всё разворачивается в Docker одной командой.

## 🛠 Стек
* **Airflow 2.9** — оркестрация и расписание.
* **ClickHouse** — хранение данных (быстрая аналитическая база).
* **Docker & Docker Compose** — вся инфраструктура в контейнерах.
* **Python** — скрипты загрузки (pandas, requests, clickhouse-driver).

## 💡 Особенности
* **Динамические даги:** Не нужно копипастить код под каждую акцию. Список бумаг берется из `config.py`, и Airflow сам создает под них задачи.
* **Идемпотентность:** Можно перезапускать загрузку сколько угодно раз — дублей в базе не будет (данные очищаются перед вставкой за конкретный период).
